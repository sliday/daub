# Playground evaluation notes

This directory tracks evaluation summaries, plans and harness source. Raw model
responses, generated interfaces, screenshots and replay corpora stay in the local
worktree; the release excludes the entire reports directory from public assets.

Artifact paths within dated reports refer to those local captures. A fresh clone
does not contain them. Harnesses that inspect or replay captures require the
corresponding local evidence directory. The generation runner can create new
captures and may incur provider charges.

Reports describe the source and checks at the time of each run. Later release
verification can cover newer changes without rewriting historical results.
