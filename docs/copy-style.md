Mode: 1 sentence-first
Locale: en-US

| Element | Case |
| --- | --- |

| Dialog, modal, and sheet title | Sentence |

| Navigation item, tab, and menu command | Sentence |
| Button, CTA, and action link | Sentence |

Never touch: DAUB, Daub Place, Daub Style, Dashrock, Tamp, Dwarf Land,
GitHub, Cloudflare, Figma, React, JavaScript, TypeScript, JSON-Render,
Claude Code, Cursor, npm, named themes, and acronyms such as AI, API,
CSS, HTML, JSON, JSX, MCP, OTP, PDF, UI, and URL. Preserve personal names,
quoted text, user-entered text, filenames, code identifiers, component
catalog names, and route slugs. Format component catalog names for display
without changing the source identifiers.

Capitalize the first word and proper nouns. Use "Case studies", "Theme
gallery", and "Chat composer". Fix the source text, not with a blanket CSS
case transform. Do not force headings to uppercase or title case.
